集計は支出枠の中だけで、研究効果を別枠にする。明細小計は総額と単価・回数から重複するため除去。必要な名前・値・単位を11px以上とし、数字全体を大きくするための余白は増やさない。入力欄に薄い境界を付け、直接編集を識別する。モバイルの集計のみ十分な高さの画面でstickyにし、支出の操作中に参照できる。低い画面では通常配置とし、スクロールやフォーカスを遮らない。

比較した案: 配色のみの調整は小さい情報と操作距離を解決しない。全カウンターの表への再編は既存の価格順とPC6列の要件から変更が大きい。既存構造を保つコンパクト化を採用する。
