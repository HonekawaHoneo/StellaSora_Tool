# 開発目的と仕様の確認

確認日 2026-11-12。UI設計前にREADME・既存設計と元の説明削減要求を照合した。

目的は、星ノ塔探索中の研究効果2種類と支出7種類を素早く数え、目標と対象支出の差を確認すること。所持コイン残高、全支出、完成ビルドの管理ではない。

公式の一次情報:
- https://stellasora.jp/news/2549 音符は装備ロスレコのアシスト条件と関係する。
- https://stellasora.jp/news/4893 研究による解放、素質の選択・強化、買い物等が別の探索行動。代理掃討ポイントは本ツールのコインと区別する。

数値の補助根拠:
- https://gamewith.jp/gamedb/12512/articles/56389 Yostar提供の先行体験記事。研究・4、難易度8以上の効果として、Lv3で出た素質を選んだ取得回数10回、＋2効果の発動5回。出現回数やカード3枚分の回数ではない。
- https://hohzuki-tries.com/stellasora-star-tower-record-guide/ 個人検証。再抽選40、5個セット90/72/45、15個セット400/320/200を既存モデルと照合した。

公式公開資料で10/5の上限や各価格を直接確認できたとは扱わない。公式告知、提供記事、非公式検証の範囲を分け、数値を変更する根拠はない。研究回数は支出に算入しない。

初期実画面はChromium/Linux、light、fixture reroll=2/note90=1/target=500。390/320px幅の文書高1249px。1280px幅は全体を一望できる。価格単位8px、割引9px、研究残数10pxが小さい。入力可能面と＋/−の実ヒット領域を維持して読みやすくする。
