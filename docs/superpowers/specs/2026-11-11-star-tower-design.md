# 星ノ塔カウンター

ステラソラの星ノ塔を遊びながら、研究効果の使用回数、素質の再抽選・音符セットの購入回数と消費コイン、目標との差額を確認する小さなブラウザーツール。

- Lv3素質の取得回数と＋2強化の使用回数を各1個のカウンターで表示し、消費コインに含めない。難易度8以上・対応研究解放時の上限10回／5回に対する残数を表示する。
- 上限は参考表示とし、上限超過した旧保存値を保持する。残り回数は0未満にせず、超過回数を併記する。
- 素質の再抽選（40コイン）、音符5個セット（90／72／45コイン）、音符15個セット（400／320／200コイン）の回数を独立して記録する。
- 合計は素質の再抽選・音符セット購入による消費コイン。素質購入・強化マシン・イベントの支出は対象外。差額は目標コイン−消費コイン合計で、超過時も負の値をそのまま表示する。
- 各カウンターに＋／−ボタンと直接入力を付ける。回数・目標値は0以上の整数。
- ワンボタンで全カウンターを0に戻す。目標値は保持する。
- PC・スマートフォン対応の簡潔な1画面。数値はブラウザー内に保存する。
- 研究効果（Lv3素質・＋2強化）、素質の再抽選、音符セットの購入を別グループにする。「記録」はゲーム内の完成ビルドと混同するためグループ名に使わない。
- 音符5個セット（通常90・20%引き72・半額45コイン）と15個セット（通常400・20%引き320・半額200コイン）に分け、各セット内は通常→20%引き→半額の順にする。
- PC（幅960px以上）は2系統を横並びにして各3列（計6列）、480〜959pxは系統を縦に並べて各3列、それ未満は価格別のコンパクトな行にする。
- 研究効果は灰色の行と記録アイコン、素質の再抽選は橙色の操作枠と回転矢印、音符セット購入は紫色のグループ枠と音符アイコンで区別する。色だけでなく形と見出しでも区別できるようにする。
- 全体の余白・カード高を抑え、低いウィンドウでもコンパクトに表示する。狭い画面でも横にはみ出さず、必要に応じて縦スクロールで操作できる。

## 実装方針

外部サービス不要の静的HTML/CSS/JavaScriptを採用する（実装側の判断）。計算モデルを独立させ、Node.js標準テストで数値・境界条件を確認し、可能な環境で実ブラウザーの表示・操作を確認する。保存キーと既存のカウンターIDを維持し、数値を引き継ぐ。既存Siteの共有範囲を維持して公開する。外部画像・実行時サービスは不要。
