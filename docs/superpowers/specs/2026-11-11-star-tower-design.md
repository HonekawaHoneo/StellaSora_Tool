# 星ノ塔カウンター

ステラソラの星ノ塔を遊びながら、9種類の回数と合計、目標との差額を確認する小さなブラウザーツール。

- 「素質3」「強化2」は各1個のカウンター。合計に含めない。
- リロール(40)、音符(45)、音符(72)、音符(90)、音符(200)、音符(320)、音符(400)を独立して記録する。
- 合計は各回数×括弧内の値の総和。差額は目標値−合計で、超過時も負の値をそのまま表示する。
- 各カウンターに＋／−ボタンと直接入力を付ける。回数・目標値は0以上の整数。
- ワンボタンで全カウンターを0に戻す。目標値は保持する。
- PC・スマートフォン対応の簡潔な1画面。数値はブラウザー内に保存する。
- 記録用（素質3・強化2）、リロール、音符を別グループにする。
- 音符6種類を各カードに分け、PC（幅960px以上）は6列で横一列、幅600〜959pxは3列、それ未満は2列（幅320px未満は1列）にする。
- 全体の余白・カード高を抑え、低いウィンドウでもコンパクトに表示する。狭い画面でも横にはみ出さず、必要に応じて縦スクロールで操作できる。

## 実装方針

外部サービス不要の静的HTML/CSS/JavaScriptを採用する（実装側の判断）。スプレッドシートは日常のタップ操作に向かず、サーバー付きアプリは今回の計算に不要。計算モデルを独立させ、Node.js標準テストで数値・境界条件を確認し、実ブラウザーで操作を確認する。Sitesで本人用に公開する。画像やゲームの外部仕様は利用しない。
