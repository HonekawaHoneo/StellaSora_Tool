# 星ノ塔カウンターの読みやすさと操作性

既存のカウンターを、ゲーム中にも読み取りやすく押しやすい画面に整える。既存のHTML/CSS/JavaScriptと保存形式を利用する。

## 方針

大きな画面構成の変更と、既存配置の読みやすさ改善を比較し、後者を実装側の判断で採用する。既存仕様のコンパクトな配置と色分けを保ち、補足文字の大きさ・コントラスト、数値の階層、入力欄の輪郭、操作ボタンの大きさを改善する。新機能や外部依存関係は加えない。

## 制約

- 全9カウンター、価格、計算、研究上限、保存キー、目標を保持するリセットを維持する。
- 研究は灰色、再抽選は橙色、音符は紫色とする。
- 音符は960px以上で2系統×3列、480〜959pxで系統を縦に並べて各3列、480px未満は価格別の行を維持する。
- ボタンは通常40px、狭い画面とタッチ操作では44pxを基本とし、480〜699pxの3列表示と960px以上の6列表示では数値をボタンの上に配置する。
- 通常の補足文は11px以上とし、見出しと入力欄に十分なコントラストを確保する。
- キーボードのフォーカス、入力エラー、動きを抑える設定に対応する。

検証は既存テスト、構文・差分チェック、利用可能な管理プレビューによる表示・操作確認を行う。プレビュー基盤が利用できない場合は未検証の範囲を明記する。既存Siteの公開範囲を維持する。
