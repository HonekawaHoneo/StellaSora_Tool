# ステラソラ 星ノ塔カウンター

9個の独立したカウンターを備える、外部ライブラリー不要の静的Webツールです。

- 「素質3」「強化2」各1個（合計には含めません）
- リロール(40)、音符(45)、音符(72)、音符(90)、音符(200)、音符(320)、音符(400)
- 合計 = リロール回数 × 40 + 各音符の回数 × 括弧内の数値
- 目標値の自由入力、差額 = 目標値 − 合計（超過時はマイナス）
- 全リセット（目標値は保持）、＋／−・直接入力、ブラウザー内の自動保存
- PC・スマートフォン対応

記録用・リロール・音符をグループ別に表示します。音符は各単価を独立したグリッドに分け、幅960px以上では6列、600〜959pxでは3列、それ未満では2列（極小幅では1列）に切り替えます。余白・文字・ボタンはウィンドウ幅と高さに合わせて調整します。

## 使い方

`dist/index.html`をブラウザーで開くだけで使えます。保存領域が制限された環境でも、カウント・計算は動作します。自動保存は同じブラウザー・URLで使用する場合に有効です。

HTTPサーバーで使う場合:

```sh
python3 -m http.server 8000 --directory dist
```

回数・目標値は0以上の整数です。JavaScriptが正確に扱える整数の範囲を超える入力・合計は受け付けません。全リセット時に確認ダイアログは出ません。

## 検証

Node.js 18以降で、依存関係をインストールせずに実行できます。

```sh
npm test
```

`dist/counter.js`が計算と入力検証、`dist/app.js`が画面操作と保存、`dist/styles.css`が表示を担当します。
